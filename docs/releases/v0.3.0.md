# PiP Opacity v0.3.0

Adds browser video PiP support beyond Firefox: Chrome, Helium, Edge, Brave, Opera, Vivaldi, and Chromium. The tray/settings display name is now PiP Opacity.

## Behavior

- Exact title, class, executable and geometry checks keep ordinary browser windows excluded.
- Chromium support currently requires the English native title `Picture in picture`. Document PiP and unknown/localized windows are excluded.
- Existing config, startup registration, icon and executable name remain compatible.
- Includes WPF settings with 0-100% opacity, optional click-through, Ctrl mouse bypass and the UI freeze fix.
- Main-keyboard Ctrl+Alt plus/minus registrations are removed to preserve AltGr typing. Numpad opacity shortcuts remain.
- Always-on-top control has been removed since v0.2.0 following media interaction issues.

## Installation

Download `PiPOpacity-v0.3.0-win-x64.zip`, extract the entire package to a permanent folder, and run `PipOpacity.Tray.exe`. The self-contained Windows x64 build does not require a separately installed .NET runtime. Exit an existing tray instance before replacing its files. If installing to a different folder, toggle Start with Windows off/on there to update the startup path.

## Verification

Release build and regression suite passed. A live Helium synthetic-video PiP smoke test verified alpha 128, click-through, effective Ctrl bypass, pause/exit style restoration and unchanged styles on 34 unmatched visible windows. Other Chromium executables have matching-fixture coverage rather than separate live browser tests. Physical Ctrl input was not synthesized in this test.
